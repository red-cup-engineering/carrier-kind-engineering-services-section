## The mathematics: what is established, what is open

- **Marks and articulation.** A primitive mark is primitive *relative to a declaration*. That does not by itself prove an ontological claim of relationlessness. Predications distinguish subject, predicate, object and witnessed valuation; stable content identities cannot certify referential fidelity.
- **FOUR.** Keep positive and opposing evidence separately. `absurd` denotes no information, `potential` positive, `active` opposing, `stable` both; knowledge and truth orders differ. Do not treat `stable` as probable, approved, or classically explosive.
- **Predication → Chu / FCA / Hilbert.** Finite closure contexts, categorical projections, adjoints and typed carriers have real implementations; the complete semantics-preserving dictionary, biextensional `Quot.sound` obligations, directed residuation and claimed Chu→Hilbert derivation remain dependent on their exact named open scientific questions. See [predication/Chu](https://github.com/lenticule-science/obsmetrologia/blob/main/docs/loop/items/predication-chu-dictionary.md) and [twistor/residuation](https://github.com/lenticule-science/obsmetrologia/blob/main/docs/loop/items/twistor-residuation-key-idea.md).
- **CHL / chromatic Lorentzian.** [Finite chain propagation](https://github.com/red-cup-engineering/computer-data-engineering-services-section/blob/main/lib/metrologic/src/articulation/predicating/positing/settling/analysis/chromatic-lorentzian.mjs) is an executable model of Boolean one-step motion and exact backward differences. Its orbit is now computed by the nearest prior mark in linear time; exhaustive bounded model tests and integer overflow refusal are in [Metrologic PR #153](https://github.com/red-cup-engineering/computer-data-engineering-services-section/pull/153). This is **not** a proof of a Lorentzian metric or manifold. [Light-cone lattice](https://github.com/lenticule-science/obsmetrologia/blob/main/docs/loop/items/light-cone-lattice.md) and [evidence spacetime](https://github.com/lenticule-science/obsmetrologia/blob/main/docs/loop/items/evidence-spacetime.md) remain research dockets.
- **Kinematic vs kinetic.** The first asks which transitions/dependencies are admissible and how they are ordered; the second also models rates, costs, resources and physical/machine effects. A dependency DAG is a valid *kinematic carrier* but does not establish kinetic dynamics or physical causality without additional typed evidence and laws. Do not conflate a proof's critical path with elapsed wall time or energetic expenditure.
- **Discrete boundaries.** [Obsmetrologia PR #45](https://github.com/lenticule-science/obsmetrologia/pull/45) and [Metrologic PR #152](https://github.com/red-cup-engineering/computer-data-engineering-services-section/pull/152) carry directed incidence and exact integer graph boundaries. Preserve edge orientation, multiplicity and cancellation; do not infer causal rule licensing or economic trading authorization from an incidence operator.

### Serious unfinished safety and production boundaries

- **Highest operational blocker:** The unsafe ambient generated-code execution path has been removed from the source-free module factory. **The host-level Guix/LAGOON isolation provider is still unverified and not deployed through this work.** Until MetroPlat composes one, the factory returns `ISOLATED_ASSAY_UNAVAILABLE` rather than silently executing untrusted code. Coesite must verify actual credential-free/read-only mounts, ephemeral scratch, network-off behavior, CPU/RAM/PID/time limits, process-tree cleanup and negative controls on the serving worker. A `run.isolated` response flag by itself does not prove these controls. The controlled local Node runner exists strictly under test fixtures, not as a serving fallback.
- **Quality/throughput gap:** The lightweight Code Engineering CI still exercises only dependency-free source and TAP-boundary tests. The Code Development Engine's full `test/jsnode-fabrication-mcp.test.mjs` is now explicitly listed in its `receivingTests` for the Guix machine's pinned package gate; execution of that complete native installed-package test and a serving sandbox negative-control suite has **not been independently observed here**. Neither a declaration nor a passing source-check substitutes for running the actual factory.
- **Customer delivery gap:** A generated module proposal is not a merged code change; a merged code change is not an installed release; a deployed service is not independent consumer acceptance. No current source readback here establishes a repeatable source-free scientific demand → generated candidate → isolated complete tests → customer repository update → production release → independent observation cycle. That is the highest-value next vertical slice.

## Fabrication science, engineering, operations, corporate value and public claims

A real device consumer must submit a typed part/toolpath/process requirement with geometry, dimensions, tolerances, machine bounds, material state, calibration source and measured environmental conditions. Separate:
- a universal theorem on an abstract construction;
- a finite computational witness or simulation;
- a measured property of a specimen or instrument;
- a license permitting a controlled machine effect.

A stable FOUR observation is a contested reading, not permission to machine a part. Exact oriented incidence can inform geometric or connectivity computations, but making G-code safe also requires machine-specific mechanical bounds and independently received controls. The existing CapCell capability-fabrication PDK packages software capabilities, not guaranteed 3D-printer toolpaths. Until a named engineering device/application consumes proof-carrying constraints, **no physical fabrication integration should be marked complete**.

The 561 Group may sell justified computations and public services may publish qualified results, without overstating licensing, correctness, scientific consensus or production-site readiness. The [subject publication source](https://github.com/lenticule-science/obsmetrological-services-section/tree/main/sites/obsmetrologia.561.group) is an editorial candidate; a Git repository is not proof that `https://obsmetrologia.561.group` serves it.
