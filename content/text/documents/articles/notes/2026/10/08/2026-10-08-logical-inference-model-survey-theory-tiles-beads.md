WHAT IS GENUINELY OURS. The house theory of tiles-and-beads is one thesis stated three ways: (1) "color is a finite observable of aperiodic order" (the 06-26 seed: five roles of color — proper coloring, matching-rule decoration, Wang edge alphabet, Markov-partition state, diffraction weight — each a factor map that preserves and forgets different things about a hull); (2) "a beadwork pattern is a finite observable of a stitch-generated order" (06-27: the stitch graph is the substrate, color is a function on it, the chart is a projection, the finished object is a record of local moves; BIT(B)=(G,κ,λ,η,δ,h) bundles graph, coloring/charge, layout, seam-obstruction H¹, autocorrelation, and log₂(#legal completions)); (3) "order lives in the stringing, not the bead" (08-16: an LLM is glass — amorphous, cannot be annealed by prompt text; confine it to one typed observable per position and let a typed thread law carry the order; the 10-02 note then reads the two hands as the two orders of Belnap FOUR, left=≤ₜ lawfulness, right=≤ₖ the accumulated past, with the lenticle = overlap where they are compared and disagreement held as ⊤ rather than rejected). The mathematically load-bearing, machine-checked core is small and honest about scope: Path/SoficImage/forgetDecoration with fib_deep_sofic (a 3-letter decorated SFT whose forgetful image is exactly the Fibonacci-substituted golden words — the toy instance of Goodman-Strauss/Vereshchagin "substitution tilings are sofic"); substitute_preserves_path (follower-SFT compatibility engine); the Jeandel–Rao finite one-vertex Anderson–Putnam bricks (b3 on 7 edges, φ on 6 edges, and the integer chain map subPull with subPull b3 = φ); the hat metatile matrix with the φ⁴:1 reflection frequency as a left eigen-relation in ℤ[φ]; the bead port law (pass legal iff in-side ≠ out-side; thread is a walk, not an edge set); occupancy→FOUR condensate (0/1/≥2 ↦ ⊥/t/⊤); h1_vanishes_iff_forest (seam obstruction = cycle rank); FOUR as a 1+1 light cone (time=pos+neg, space=pos−neg, KLE ⟺ |Δspace| ≤ Δtime) with the D4 gauge fact swap∘neg∘swap = conflate ("swapping the hands turns a mirror into a time reversal").

WHAT IT COMPUTES, VERSUS WHAT IT CLAIMS. The executable layer (metrologic) is a finite "shadow": directed-walk checking in a boolean adjacency matrix, 1-block relabelling, word substitution, incidence-matrix abelianization, char-poly/Smith/rank, matrix powers (called "Bratteli port-growth tower"), brute-force proper-coloring counts, cyclic pair-difference autocorrelation, 1-D cut-and-project model sets with a per-period refuter, and a 2-D BLOCK substitution + grid adjacency for chromatic number. There is NO Wang-tile matcher anywhere (no tile set type, no row-to-row edge-matching transducer); "Jeandel–Rao" in code is transcribed cohomology incidence data, not the 11 tiles. "mutuallyLocallyDerivable" compares (rank, det, Smith, stableDet, inverted primes) of two incidence matrices — a coarse shift-equivalence-flavoured invariant, not MLD. The "aperiodic regime" is three Boolean flags; cl-inv is an Int coordinate with aperiodicWitness = ⟨1⟩; "cohomologyVanishes" is a declared table. The 10-02 two-hands note cites Autopoiesis.history_separation_aperiodicity as proved; the Lean file says the opposite (HistorySeparationForcesAperiodicity is stated with an undefined parameter map and is open; the proved theorem is varying_family_beside_aperiodic_witness, three facts "with no map between them"). kinetic_forced_by_residue is arithmetic on ℕ²: adding a nonzero constant record each lap never repeats. The relationality notes "aperiodic germ / tiling-constraint / local-rule-completeness / aperiodic-extension" are status:plan stubs with empty proof_refs and no code. The 06-26 beadwork survey is largely an externally generated literature survey (chatgpt utm tags, fileciteturn markers); the house contribution in it is the seven-term beadwork formula, the port-graph proposal, and the open-problem table (notably #12 "aperiodic beadwork systems", #15 "verified bead-chart compiler").

THE GENERATION MODEL THESE PIECES ACTUALLY SUPPORT. Row-by-row making = walking a finite transition graph: the next symbol/row must satisfy a local compatibility predicate with the previous one (1-D Path; 2-D would be a Wang row transducer, not yet built). Local greedy extension cannot by itself force aperiodicity (Wang tiling undecidable; local completion deadlocks), so the house's actual mechanism for "locally lawful, globally non-repeating" is the DECORATED SOFIC COVER: generate in a hidden-state SFT whose decoration carries the supertile/hierarchy role (the maker's hidden stitch state: turn/increase/join), then emit the visible symbol by forgetting the decoration (fib_deep_sofic is the worked case; 06-27 §9: "the chart is one legal configuration; the system is the set of all legal configurations"). SUBSTITUTION is the macro-planner: inflate supertiles by a primitive integer matrix (Perron growth a metallic/Pisot number; Fibonacci x²−x−1, Padovan x³−x−1, hat φ⁴), zero entropy rate yet nonperiodic — "creative but not random"; the SFT cover has positive entropy log₂(Perron) which upper-bounds it. TWO HANDS = two independent judgments on every emitted bead: left checks SFT admissibility (law, ≤ₜ), right checks agreement with the accumulated record (≤ₖ, which only climbs — HistorySystem prefix order); the LENTICLE census counts where they disagree and holds each disagreement as a ⊤ cell (H⁰_⊤) instead of backtracking — paraconsistent generation where defects are curvature (twelve pentagons on a sphere; the odd bracelet's seam fails by cycle rank). SEAMS: closing a row into a cylinder/bracelet is an H¹ check (cycle rank |E|−|V|+|C|), the one global test local generation must pass. ENTROPY is the creativity dial: log₂(#legal continuations) distinguishes forced chart (0 bits), guided improvisation (positive, bounded by local rules), substitution (0 rate, long-range order), random soup (high). The house already has a native generator in signcraft/inference/generate.mjs (enabled cone from DG-basis implications + FCA realized continuations, scored ΔF = α·opened − β·closed + T·ΔE, Gibbs-drawn with witnessed excluded mass); it is FCA+light-cone-shaped but has no aperiodicity engine — nothing in it is a substitution or a decorated cover, and it will settle into a closed concept (strict regime). That is the gap the tiles/beads theory is supposed to fill.
