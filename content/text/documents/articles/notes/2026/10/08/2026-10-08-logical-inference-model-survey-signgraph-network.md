# Logical inference model survey: signgraph-network

## Summary

SignGraph (lib/emsenn/services/561-group/services/engineering-services-section/services/computer-engineering-services-section/lib/signstuff/signgraph, ~3100 lines of .mjs in src/) is NOT one coherent networking library. It is five unrelated strata sharing a package.json: (A) a SignCell-triple "predication site" stack (site, valuation, fiber, paths, cohomology) that is small, honest finite combinatorics over FOUR-valued evidence with a hyperdoctrine flavour; (B) a genuinely numeric core, cellular-sheaf.mjs, a real cellular-sheaf implementation (coboundary, sheaf Laplacian, exact Q-cohomology via BigInt rank, deterministic heat flow with pinned boundary vertices and 'firing' edge crossings, CGLS normal solve with an obstruction vector, and bar/body-bar rigidity sheaves); (C) a Chu-space layer (cell-graph, chu-term) that is mostly a thin wrapper over metrologic/chu.mjs plus a SEN-term re-encoding of dual/lookup; (D) a content-addressed, notarial 'die/circuit' layer (hierarchical-circuit, circuit-trace, carrier-refinement, relational-value) which is a real, careful implementation of monotone FOUR-valued gate-level composition with tensor/par nets, Kleene least-fixed-point settlement, factored behavior tables, and a closed-loop holonomy check in the group C4 semidirect Z^2; (E) ingestion/projection plumbing (pam, relation-adapters, mesh, graph, diagram*), where mesh is real FCA on claim profiles and pam is an event-sourced reader that folds EAVT relation-web observations into SignCell valuations. The README is out of date: it lists only cell-graph, graph, cellular-sheaf, relation-adapters, pam, while package.json exports 21 modules (site, valuation, fiber, cohomology, paths, mesh, chu-term, hierarchical-circuit, circuit-trace, carrier-refinement, relational-value, diagram*). Tests exist for only 7 modules (carrier-refinement, cell-graph, cellular-sheaf, chu-term, graph, hierarchical-circuit, relational-value); none for site, valuation, fiber, cohomology, paths, mesh, pam, circuit-trace.

What it actually computes, as a substrate for a new AI: (1) a deterministic, exact, auditable local-to-global consistency operator: sheaf Laplacian L=delta^T delta with Gershgorin step, diffusion to the harmonic section = orthogonal projection onto H0 (global sections), plus exact H1 as the obstruction count. This is the only module that is a bona fide message-passing / transport / attention-substitute primitive: restriction maps are learned-free typed 'messages' F_{v<e}, residual ||(delta x)_e|| is a per-edge disagreement score, pinned vertices are evidence/boundary conditions, and solveNormal returns an explicit 'obstruction' for loads the sheaf cannot carry. It is linear (no nonlinearity, no weights learned), all stalks are real vectors (not FOUR-valued), and the Laplacian is rebuilt from scratch on every call and uses Map-based sparse rows plus findIndex vertex lookups (O(V) per lookup), so it does not scale to model-size graphs as written. (2) a monotone FOUR-valued logic network: circuits whose leaves are complete 4^k truth tables (capped at 6 inputs per irreducible factor, 4096 rows), required to be monotone in the knowledge order, composed by nets with tensor vs par modes, settled by iterating joins to the least fixed point within a finite-height bound. This is a discrete, verifiable alternative to a neural layer ('logic circuit with paraconsistent values'), with content-address identities for every component (ni: SHA-256 URIs) so composition is hash-checked (component-drift). (3) a Chu/FCA/hyperdoctrine layer for organizing readings: fibers over predicates with pullback and left/right adjoint quantifiers (exists = join fold, forall = meet fold) for converse, subject/object projection, and specialization, with Frobenius reciprocity and fusion/residuum preservation checkable; mesh.generatedConcepts computes extents/intents over the formal context (subjects x claims) from metrologic closure/formal-context. (4) a discrete connection: circuit-trace composes seam receipts into an element of C4 semidirect Z^2 (quarter turns + integer translation) around a closed net loop and classifies it (closed-flat, translational-defect, rotational-protected-border, mixed-affine-defect, chu-seam-mismatch, unpriced-irreversible-defect). This is the single piece that resembles tile gluing / holonomy / Wang-tile edge-matching, but it is audited bookkeeping over supplied receipts, not a tiling engine.

Missing relative to the vision: no light cones or causal order (PAM only has a total order via ordinal/relationIndex windows 'until'/'after'; paths.mjs composes label sequences one round with no causal structure); no tiling/Wang/substitution/sofic machinery; no beadwork; no CHL (type/term/proof) link in this package except implicitly via chu-term/relational-value SEN typing; no learning, no embeddings, no nonlinear attention, no stochasticity; no sheaf-of-FOUR (the cellular sheaf is numeric R^d, the site/fiber layer is FOUR but has no Laplacian), so the two halves that would make a 'foam' have never been joined. Several large names (hierarchical-circuit 'RMN die', 'sovereign recursive assemblies', 'economicCurrentAffinity', 'priceErasure', CAIP-10 accounts, 'Rendanheyi' membranes) are domain-specific settlement/compliance machinery layered on a small core; strip it and the core is: monotone FOUR gates + nets + least fixed point + content addresses.

## Abstractions

### cellularSheaf / constantSheaf / cochain

- **File:** `lib/emsenn/services/561-group/services/engineering-services-section/services/computer-engineering-services-section/lib/signstuff/signgraph/src/cellular-sheaf.mjs`
- **Computes:** cellularSheaf({vertices:[{id,dim}], edges:[{id,from,to,dim,restrict:{from:M,to:M}}]}) -> frozen validated sheaf with flat offsets (vertexOffsets, edgeOffsets), c0=sum vertex dims, c1=sum edge dims, exact flag (all entries exact rationals). Ids by SignCell coincidenceKey. constantSheaf = identity restrictions R^dim; cochain builds a flat 0-cochain from [{vertex,value}]. Validation is O(V+E) except cochain/diffuse pin lookup uses findIndex (O(V) each).
- **Theory:** Cellular sheaf of vector spaces on a graph (Curry/Hansen-Ghrist): stalks F(v), F(e), restriction maps F_{v<e}. Genuinely realized: dimensions, restriction shapes, and ids are checked. Only vertex-edge incidences (a graph, not a general cell complex); no higher cells, no FOUR-valued stalks.

### coboundary / sheafLaplacian / applyLaplacian / apply / applyTranspose

- **File:** `lib/emsenn/services/561-group/services/engineering-services-section/services/computer-engineering-services-section/lib/signstuff/signgraph/src/cellular-sheaf.mjs`
- **Computes:** delta0 as a sparse row-list matrix ((delta x)_e = F_{to<e} x_to - F_{from<e} x_from); L = delta^T delta built by outer-product accumulation of each delta row into Map rows; apply/applyTranspose do deterministic fixed-order sums. L is recomputed on every applyLaplacian/diffuse/hodgeCheck call (no caching).
- **Theory:** The sheaf Laplacian L=delta^T delta (symmetric PSD), ker L = ker delta = H0 (global sections). This is the message-passing operator: each edge compares transported neighbor values via restriction maps and pushes residual back. Real and correct; it is a fixed linear operator, so as 'attention' it is static, content-independent weights unless restriction maps are made input-dependent.

### cellularSheafCohomology

- **File:** `lib/emsenn/services/561-group/services/engineering-services-section/services/computer-engineering-services-section/lib/signstuff/signgraph/src/cellular-sheaf.mjs`
- **Computes:** Exact dim H0 = c0 - rank(delta), dim H1 = c1 - rank(delta) over Q using BigInt 'n/d' strings and ratRank from number/rational-matrix (dense exactCoboundary matrix; rows built as [n,d] BigInt pairs). Throws if any restriction entry is inexact float. Output {h0,h1,vanishing,rank,c0,c1}.
- **Theory:** H0 = global sections (consistent assignments), H1 = obstructions to gluing / self-stresses. Truthfully exact for the rank computation; dense Gaussian elimination in BigInt rationals so cubic and heavy for large nets. H1 vanishing is wired to rankVanishing witnesses from cohomology.mjs.

### diffuse / harmonicProjection / hodgeCheck / gershgorinBound

- **File:** `lib/emsenn/services/561-group/services/engineering-services-section/services/computer-engineering-services-section/lib/signstuff/signgraph/src/cellular-sheaf.mjs`
- **Computes:** Heat flow x <- x - alpha L x with alpha = 1/Gershgorin(L) (largest absolute row sum), pinned vertex components held fixed and excluded from the gradient, stop when ||free gradient|| <= tolerance (1e-12) or maxSteps (1e5). Returns {section,residual=||delta x||,gradient,steps,converged,firings,crossings}; crossings record per-edge 'settled'/'violated' transitions when ||(delta x)_e|| crosses tolerance. hodgeCheck diffuses without pins and checks L-residual and section residual.
- **Theory:** Gradient flow of energy 1/2||delta x||^2 -> harmonic section (orthogonal projection of x0 onto H0 when unpinned); with pins it solves a Dirichlet problem (boundary evidence). The 'firing' list is just threshold-crossing bookkeeping, not a dynamical discontinuity: the update is smooth, so 'firing vs smooth steps (ClosureFlowDynamics)' in the doc comment is an after-the-fact label on edge residual thresholds. Deterministic IEEE arithmetic (no transcendentals). This is the closest thing in the repo to a relaxation/inference loop usable as 'attention substitute': a convergent consistency-seeking diffusion, with explicit boundary evidence and per-edge disagreement trace.

### solveNormal (CGLS) with obstruction

- **File:** `lib/emsenn/services/561-group/services/engineering-services-section/services/computer-engineering-services-section/lib/signstuff/signgraph/src/cellular-sheaf.mjs`
- **Computes:** Solve delta^T f = rhs for the minimum-norm 1-cochain f by conjugate gradients on normal equations, from f=0; rhs is a 0-cochain load. If rhs has a component in ker delta (H0) the system is inconsistent and the unresolvable part is returned as obstruction = rhs - delta^T f (never NaN). Returns {section,obstruction,residual,rhsNorm,steps,converged,consistent}.
- **Theory:** Dual transport: loads on vertices carried to edge flows (statics: forces from loads). The returned obstruction in ker delta is the harmonic part that the sheaf cannot transport. As a primitive it is a clean 'what can be routed vs what is stuck' split; it is the dual (transport/flow) of diffuse (consistency/relaxation).

### rigiditySheaf / rigidityReceipt / bodyBarSheaf / bodyBarReceipt

- **File:** `lib/emsenn/services/561-group/services/engineering-services-section/services/computer-engineering-services-section/lib/signstuff/signgraph/src/cellular-sheaf.mjs`
- **Computes:** Bar-framework rigidity matrix as a sheaf (stalk R^d per joint, R^1 per bar, both restrictions = direction row; exact differences over Q, or normalized with Math.sqrt for floats) and Tay-Whiteley body-bar sheaf (stalk R^6 = (v,omega) per rigid body; constraints 'bar' 1 row, 'pin' 3 rows, 'hinge' 3+2 rows). Receipts give motions=H0, mechanisms = motions - d(d+1)/2 (or 6 per piece), selfStresses=H1, a Maxwell identity check mechanisms - selfStresses = 6(bodies-pieces) - rows, and rigid flags. Used by apps/holofoam/src/structure.mjs.
- **Theory:** Maxwell/Calladine counting as sheaf cohomology: motions are H0, self-stresses H1. Correct and genuinely used downstream (holofoam). This is the structural-mechanics 'foam' hook: a bubble/cell complex of rigid bodies with contact constraints has exactly this cohomological reading. Not connected yet to any inference model.

### cohomologyOfCells / cohomologyLaplacian / cohomologyReceiptOfCells

- **File:** `lib/emsenn/services/561-group/services/engineering-services-section/services/computer-engineering-services-section/lib/signstuff/signgraph/src/cohomology.mjs`
- **Computes:** For SignCell triples read as directed 1-cells subject->object: entity list (uniqueBy O(n^2) via coincides), integer incidence matrix I (cells x entities, +1 object, -1 subject), components by union-find, H0 rank = #components with component-indicator cocycle basis, H1 rank = |cells| - |entities| + #components (cycle rank / first Betti number). cohomologyLaplacian: L = I^T I with safe-integer check, exact charPoly, ranks via exact-number, plus rankIdentity witnesses (H0 = |E| - rank I). Also cohomologyOfEdgeGraph, componentsOf, linkGraphNerve (case-folded undirected link graph nerve).
- **Theory:** Cohomology of the constant sheaf Z on the graph of a predication set; the predicate label is ignored (all predicates collapse to 'edge'). So H1 counts cycles of ANY predicate, not logical inconsistency. Duplicates with cellular-sheaf constantSheaf(dim=1); the file itself says it agrees. Cleanly correct, small, and a good cross-check; the real structure belongs in cellular-sheaf.

### pricedNerve / pricedCell (federated cover obstruction)

- **File:** `lib/emsenn/services/561-group/services/engineering-services-section/services/computer-engineering-services-section/lib/signstuff/signgraph/src/cohomology.mjs`
- **Computes:** Input: statements [{source, cell, stance, witness?}]. Per cell, per measurement: tallies of sources telling true and false -> record(t,f) -> FOUR reading (readingOfRecord) and topMass; 'top' = # measurements held both-true-and-false (contradiction), 'mass' = counting-merge contradiction mass, 'rank' = H1 rank of the source-measurement context-incidence base (coverNerve). Output {top,mass,rank,vanishing,cells,obstructions}. Two modes: cell-as-register (stances are values) or cell-as-claim (stances are reading names).
- **Theory:** Contextuality/obstruction pricing: top=0 iff the sources are compatible (locally consistent family glues, per Obsmetrologia mergeRecord_topfree_iff_compatible); the doc admits the causal leg (e) and mint/jump legs (c) are NOT computed (needs a causal order the statements lack). So it is a counting disagreement measure over sources, a real paraconsistent-ledger primitive and the cleanest 'multi-source evidence conflict' score in the package, but 'colimit max(mass, causal)' is only read from below.

### site / specialization / transportRules / closeSpecialization / cohere

- **File:** `lib/emsenn/services/561-group/services/engineering-services-section/services/computer-engineering-services-section/lib/signstuff/signgraph/src/site.mjs`
- **Computes:** site(cells+specializations) -> {cells (unique triples), entities, predicates, specializations, base} where base lists objects (entity|predicate sort) and generated morphisms (converse, subject/object projection per cell, specialization). closeSpecialization is a naive O(n^3)-per-pass transitive closure over predicate edges. transportRules(site) emits SignChain rules: specialization-for (for-evidence at specialized predicate => potential at general; atLeast potential) and specialization-against (active against general => active against specialized) restricted to cells present in the site. unrelatedPairs, utteranceSite, presentSite/freeSite, siteGeneratorsSchema (JSON Schema).
- **Theory:** RDFS subPropertyOf (rdfs7) as inference rules over a four-valued bilattice; the 'small category' is presented (generators only), no composition law or functor laws are checked, and the category is not closed under composition (only specialization is closed). Honest and tiny. Useful as the rule-generation front end of a logic net: sites -> transport rules -> SignChain settlement.

### valuation / presheaf / sheafOfValuation

- **File:** `lib/emsenn/services/561-group/services/engineering-services-section/services/computer-engineering-services-section/lib/signstuff/signgraph/src/valuation.mjs`
- **Computes:** A valuation is a SignCell cell set; evidenceAt returns the cell at a triple or the told-nothing cell. Operations: knowledge join (mergeCellSets), knowledge leq cellwise, sameValuation, posit(site,valuation) -> {kind:'signgraph.presheaf', site, traces:[valuation]} (refuses cells outside site), withTrace appends a valuation, sheafOfValuation just wraps the section, present/freePresheaf. Membership tests are O(n*m) via sameCell.
- **Theory:** Presheaf of FOUR-valued evidence over the site; knowledge-ordered join-semilattice of valuations. The 'sheaf' is merely a tag around a valuation - no gluing/descent condition is checked. 'presheaf' is a trace history (a list), not a functor. Names exceed content: this is a typed list of cell sets with a join.

### predicateFiber / generators (converse, subjectProjection, objectProjection, specialization) / Frobenius

- **File:** `lib/emsenn/services/561-group/services/engineering-services-section/services/computer-engineering-services-section/lib/signstuff/signgraph/src/fiber.mjs`
- **Computes:** A fiber is a FOUR-valued matrix over (subject,object) pairs of an entity list (lookup by linear find with coincidence). Generators give pullback, exists (fold join in knowledge or truth order) and forall (fold meet), e.g. subject-projection: exists folds a row onto the diagonal. fiberFusion/fiberResiduum cellwise (SignChain linear logic), fiberLeqTruth, generatorPreservesFusion/Residuum, generatorSatisfiesFrobenius checks (exists(pullback(a) x phi) = a x exists(phi)). fiberOfValuation reads a valuation at a predicate.
- **Theory:** Lawvere hyperdoctrine: quantifiers as adjoints to pullback along cell moves, over a base of linear-logic (fusion x, residuum ->) FOUR-valued fibers. The adjunction itself is not verified, only pullback-vs-fusion, pullback-vs-residuum and Frobenius per instance. Each fiber is O(N^2) entities^2 with linear `at`, so N^4 for ops; fine for toy. This is the closest thing here to 'predication algebra': a FOUR-valued relational algebra with converse, projection, existential/universal. It is the natural semantic of a predicate-algebra layer.

### cellGraph / relationGraphOfCells / relationGraph / flowNetwork

- **File:** `lib/emsenn/services/561-group/services/engineering-services-section/services/computer-engineering-services-section/lib/signstuff/signgraph/src/cell-graph.mjs`
- **Computes:** cellGraph(cells, observations): evaluate each named total observation on each cell -> Chu space via metrologic chuSpaceOfEntries with samePoint=coincides, sameState = name equality. relationGraphOfCells(cells): term list (indexOf by coincidence, O(n) each) and a symmetric integer weight matrix counting cells per undirected pair (reflexive cells skipped; weights recomputed by filtering all pairs for every matrix entry, O(T^2 * P)). flowNetwork(section) gives oriented edges subject->object for metrologic's boundary operator.
- **Theory:** A Chu space is points x states with a FOUR-valued pairing r: this is true only of cellGraph, where states are just named predicates evaluated on cells (formal-context-like). Re-exports transpose, dual, relationTransform etc. from metrologic's bilattice-relation (a path 'bilattice-relation' that the README names but the code imports metrologic/chu - doc drift). relationGraph is just an adjacency count matrix, not a Chu structure; it feeds metrologic's Laplacian.

### chuDualTerm / chuLookupTerm / chuDualInvolutionTerm

- **File:** `lib/emsenn/services/561-group/services/engineering-services-section/services/computer-engineering-services-section/lib/signstuff/signgraph/src/chu-term.mjs`
- **Computes:** SEN (semiotic expression notation) lambda terms, De Bruijn encoded via tm.lam/fold/cond/coincide, over JSON Chu spaces {pts, r:[{pt,st,reading}], sts}. dual: swap pts/sts, transpose each entry's pt/st and apply FOUR negation by a cond-chain over readingFamilies.knowledge; lookup: linear fold scanning r for first (pt,st) match else 'absurd' (no short-circuit actually avoids traversal; the fold visits every entry with an accumulated found flag, O(|r|)); dualInvolution: returns true iff dual(dual(s)) = s.
- **Theory:** *-autonomous dual (-)^perp of Chu(FOUR) as an executable program in the object language: a Curry-Howard-Lambek-style 'proofs as programs' artifact, the only place in this package where a Chu operation exists as a term rather than a JS function. The doc comment hard-wires RelMath theorem names (Positing.negate_negate, ChuSpace.dual_involution); the code only evaluates the involution on a given input and does not prove it. It duplicates metrologic/chu.mjs dual/transpose in term form; no tensor, par, linear implication or Chu morphisms exist as terms. Doc examples import 'relating' (@red-cup-engineering/relating) which is not in package.json - stale.

### hierarchical circuit: normalize / behaviorAt / synthesizeCircuitBehavior / verifyCircuitEquivalence / verifyCircuitFamily

- **File:** `lib/emsenn/services/561-group/services/engineering-services-section/services/computer-engineering-services-section/lib/signstuff/signgraph/src/hierarchical-circuit.mjs`
- **Computes:** Circuits are {profile, law (ni), ports (name,direction,predicate ni,carrier ni,mode tensor|par), instances (name,component ni), nets (driver, sinks, mode, chain CAIP-2, contract ni), behavior.factors}. Leaves have complete FOUR truth tables (4^k rows, k<=6 per irreducible factor), checked complete, duplicate-free and MONOTONE in the knowledge order (O(rows^2)). Composites are elaborated against a library keyed by content address, checking each net preserves predicate, carrier and mode, each pin routed exactly once, par nets carry chain+contract and tensor nets do not ('consensus-leak', 'unsettled-par'). synthesizeCircuitBehavior unions nets by union-find over child behavior factors to recover independent factors, and for each factor enumerates 4^|inputs| input rows, settling by iterating child behaviors and joining until no change (bound 2*nets+2*instances) = least knowledge fixed point; verifyCircuitEquivalence asserts the declared behavior equals the synthesized one.
- **Theory:** Monotone FOUR-valued logic networks as compositions of typed 'predicate pin' modules, with tensor (concurrent/factorable) vs par (consensus-requiring) modes: a Kleene-style fixpoint semantics over Belnap's bilattice, and the closest thing in the repo to a typed compositional (Lambek-ish) category of components with identity by hash. The 'factored behavior' (each pin in exactly one factor) is a genuine tensor-factorization to avoid exponential global tables, but synthesis still enumerates per-factor inputs and re-settles the whole circuit per row (no sharing). It is a verifier/synthesizer for a discrete logic layer, not a trainable one. Heavily lawyered domain naming (sovereign recursive assemblies, die material, RMN profile) around a small core.

### circuit assembly / realization / context reading / assay request

- **File:** `lib/emsenn/services/561-group/services/engineering-services-section/services/computer-engineering-services-section/lib/signstuff/signgraph/src/hierarchical-circuit.mjs`
- **Computes:** normalizeCircuitAssembly {circuit ni, placements:[{address:[names], membrane:{account CAIP-10, authority, custody, territory}}]}; verifyCircuitAssembly checks each placement address resolves to an instance path and returns circuitContexts; verifyCircuitRealization checks an interface; readCircuitContext(address) returns the local context; encodeCircuitAssayRequest/assayHierarchicalCircuitRequest/decodeCircuitAssayReceipt wrap it as relational-value terms.
- **Theory:** Assigns each node of the circuit hierarchy a sovereign 'membrane' (who controls it). This is the Rendanheyi/Huidu-style org layer fused into the data structure. Algorithmic content is path resolution + hash checks; the substantive theory is in membrane vocabulary, not computation. A hook for assigning cells of a foam to agents.

### assayCircuitTrace (closed-loop affine holonomy)

- **File:** `lib/emsenn/services/561-group/services/engineering-services-section/services/computer-engineering-services-section/lib/signstuff/signgraph/src/circuit-trace.mjs`
- **Computes:** Given a closed trace of <=64 par-net seams, each with a receipt {chain, contract, orientation +-1, chu {left,right} FOUR, connection {frame ni, quarterTurns 0-3, translation [x,y] BigInt-strings}, priceErasure {unit, irreversible, price}, economicCurrentAffinity {current, affinity rationals}}, it checks route closure and origin authority (receipt.originatingSettlement == membrane account of the origin instance), replay, and a single ambient frame; folds the seams in C4 semidirect Z^2 (composeAffine, rotateVector, orientedAffine inverse), sums oriented price per unit, flags irreversible-unpriced receipts, sums current*affinity as exact rationals, and emits one of: chu-seam-mismatch, unpriced-irreversible-defect, closed-flat, translational-defect, rotational-protected-border, mixed-affine-defect (or fails undeclared-border-class).
- **Theory:** Holonomy of a discrete connection around a loop (a group-valued 1-cocycle's monodromy, 'flat iff trivial'), with an orthogonal lattice-symmetry group - this is formally the same data as edge labelling of a square-grid tile adjacency (rotation + shift), and the only bit of the package that smells like tile coloring/Wang-gluing: zero holonomy = tiles glue consistently around the loop. But it only checks a supplied trace; nothing generates or searches tilings. The Chu 'left==right' seam test is a FOUR equality, a thin Chu condition. The group is hard-coded (C4 x Z^2); 'priceErasure' and 'economicCurrentAffinity' are accounting bolt-ons (Landauer-flavoured naming) with exact rationals.

### relational-value codec

- **File:** `lib/emsenn/services/561-group/services/engineering-services-section/services/computer-engineering-services-section/lib/signstuff/signgraph/src/relational-value.mjs`
- **Computes:** encodeRelationalValue(json) -> {type: RELATIONAL_VALUE_TYPE = prod(Entity, prod(list Node, list Ground)), term}: any canonicalized JSON value as a graph of ni-addressed nodes (kind: record|sequence|null|boolean|integer|decimal|text|bytes) and 'ground' triples (entity, mark, entity); relationalValueId = semantic content address of the ascription; decodeRelationalValue reverses it, with canonical decimals, NFC normalization, bytes as base64, typed against SEN with judgeSen; identify/admit/verifyRelationalValuePayload for token/claim checks.

This is the content-addressed evidence substrate bridge: every circuit, receipt and refinement certificate is hashed through it. A solid, typed (SEN) serialization; no semantic content beyond canonical identity.

### carrier-refinement receipt

- **Computes:** normalize/encode/decode of a CircuitCarrierRefinementReceipt {behavior, carrier, component, materialRoot, observation, producer, provider (CAIP-10 EVM accounts), proof, proofProfile, equivalent must be true, customerMaterialMutated must be false}, encoded via relational-value. Pure schema validation; nothing is verified against any proof.

### mesh (profiles, claims, generatedConcepts, compareReadings)

- **File:** `lib/emsenn/services/561-group/services/engineering-services-section/services/computer-engineering-services-section/lib/signstuff/signgraph/src/mesh.mjs`
- **Computes:** For cells {subject,predicate,object,for[],against[]}: claimOf(cell)=JSON [predicate,object] ('predicate with object supplied', Frege-unsaturated), profile = claims some witness tells for; settledness = SignChain census of knowledge readings; witnessing counts; relationalPredicates picks predicates whose objects are mostly terms; generatedConcepts({subjects,predicates,minimumClaims,minimumSupport}) builds a formal context (subjects x claims with support filtering), computes each subject's concept (extent via metrologic closure/formal-context, intent), groups by extent to find aliases (same extent) and 'broader' (subject whose extent contains others); compareReadings gives jaccard on claim profiles and a verdict copies|same-concept|related|unconnected by hard-coded thresholds (0.5, 0.6, 0.15, 0.1).
- **Theory:** Formal Concept Analysis on an actual data-derived context: objects = subjects, attributes = (predicate,object) claims, incidence = told-for. This is the only real FCA computation in SignGraph. It computes concepts only per-subject (the concept generated by each subject's profile), NOT the full concept lattice, no implication bases/stem base, no attribute exploration, no FOUR/paraconsistent incidence (against-evidence is ignored for profile; only settledness counts it). Thresholds are magic constants. A strong, concrete hook for FCA-based generalization.

### paths (compose / atomic / composeAndReopen)

- **File:** `lib/emsenn/services/561-group/services/engineering-services-section/services/computer-engineering-services-section/lib/signstuff/signgraph/src/paths.mjs`
- **Computes:** compose(edges): all edges plus every composite (a,[p,q],c) of two distinct edges where left.object coincides with right.subject, labels concatenated; O(n^2) coincides; one round only, not transitive closure. atomic filters single-label edges; composeAndReopen returns {composed, reopened, residue (label sequences)}.
- **Theory:** One step of the free-category/path-monad multiplication; residue = composite label sequences that no single predicate names. Sketch only: a real path category needs iteration, identities and associativity/equivalence of composites (e.g. a;(b;c) vs (a;b);c are the same here by flattening, but loops and i != j restriction make it not a category). No light-cone, no time-ordering.

### createPam / reifyMessage / replayPam (Predicate Algebra Modeling)

- **File:** `lib/emsenn/services/561-group/services/engineering-services-section/services/computer-engineering-services-section/lib/signstuff/signgraph/src/pam.mjs`
- **Computes:** reifyMessage({sender, claims[{subject,predicate,object,polarity for|against,evidence?}], id?}) -> immutable pam.message with semantic id when absent. createPam({web}) over an EAVT relation web (@red-cup-engineering/eavt/relation-web): dispatch(message) observes claims into the web (idempotent/duplicate-aware) and returns read witnesses; valuation(window{until|after}) rebuilds a SignCell map by folding ALL web observations into witnessFor/witnessAgainst per cell address each call (full O(history) rescan per read/query); read(cell), query(pattern incl. reading filter), reindex(move) = a pulled-back view through a cell move, neighbors(term, direction, predicate), messages(), replayPam(messages).
- **Theory:** Event-sourced paraconsistent knowledge base: append-only messages with polarity, valuation = fold into a FOUR reading per triple (for/against witnesses), windowed by total row order (ordinal, relationIndex) = a linear-time cut, the only temporal notion; 'reindex' is precomposition with a cell move. This is the closest thing to an agent message-passing protocol here (sender, claims, content-addressed id), but it is a store with queries, no propagation of consequences (transport rules are in site.mjs, not applied here). README's claim that PAM is 'graph-backed predicate-algebra modeling' fits only loosely; the 'algebra' is the FOUR witness count.

## Capabilities a logical inference model can build on

- cellular-sheaf.mjs is a ready, exact, deterministic sheaf-diffusion substrate: define one stalk per agent/cell/token and one restriction pair per relation; diffuse() gives consistency-seeking message passing with pinned boundary evidence and a per-edge residual/firing trace; solveNormal() routes loads to edge flows and returns the un-routable obstruction. Cohomology (exact over Q) gives certified counts of global sections (H0) and contradictions/stresses (H1) as an inference-time consistency certificate. This is the best candidate for the transport / attention-substitute core (restriction maps = typed messages; Laplacian = attention-like mixing with fixed weights).
- hierarchical-circuit.mjs provides a verifiable discrete logic layer: monotone FOUR-valued gates (Belnap), tensor/par nets, least-fixed-point settlement, factored behavior tables, content-address identity per component (hash-checked library). Can serve as the 'logical inference' nonlinearity: a deductive-truth planning layer that is checkable rather than trained.
- fiber.mjs supplies a FOUR-valued predicate/relational algebra with converse, projections, exists/forall (adjoints to pullback), fusion and residuum (linear logic), and law checkers (Frobenius, pullback commutes with fusion/residuum). This is directly the semantic domain for a predication-algebra model, and generators are exactly the 'cell moves' (converse, subject/object projection, specialization).
- site.mjs transportRules + SignChain rules: automatic generation of for/against evidence propagation rules from a specialization hierarchy (rdfs7 as bilattice rules) that SignCraft can settle; a rule-compilation front end.
- mesh.generatedConcepts + metrologic closure/formal-context: a working FCA reader of any cell body (subjects x (predicate,object) claims) with support filtering, alias detection and subsumption; gives concept formation / abstraction from evidence.
- cohomology.pricedNerve: multi-source contradiction pricing (top, mass, H1 rank) over a federated cover; a paraconsistent consensus/conflict score for an ensemble of agents or heads, with the Obsmetrologia theorem names attached.
- circuit-trace.assayCircuitTrace: group-valued loop holonomy in C4 x Z^2 with exact rational accounting and typed dispositions; a template for tile-gluing consistency checks, aperiodic-tiling cocycle tests (rotational protected borders) and flat/curved classification of a loop of seams.
- relational-value.mjs: canonical typed-graph encoding of arbitrary JSON as ni-addressed (subject, mark, object) cells with a SEN type; content-addressed evidence substrate for any model state, weights or traces (serialize a sheaf, circuit or trace and hash it).
- pam.mjs: event-sourced message dispatch (sender, claims with polarity, semantic ids), windowed replays (until/after row order), reindex via cell moves, neighbors: a ready communication protocol and ledger for a population of nodes, replayable deterministically.
- chu-term.mjs: an executable Chu-dual, lookup and involution-witness in the SEN term language: an existing example of Curry-Howard-style typed-term implementation of a *-autonomous operation, extensible to tensor/par/linear implication terms.
- cell-graph.cellGraph + metrologic/chu.mjs (chuSpace, chuMap, dual, transpose, withChu, plusChu, truthDominanceFrontier, chuLawReceipt): a Chu-space organization of cells vs observations with morphism checking, a contract between two organizations (forward map, backward demand).

## Gaps and slop

- README is stale: lists cell-graph, graph, cellular-sheaf, relation-adapters, pam but package.json exports 21 modules (site, valuation, fiber, cohomology, paths, mesh, chu-term, hierarchical-circuit, circuit-trace, carrier-refinement, relational-value, diagram*, ...). It also claims graph.mjs has 'traversal, cycle, path, merge, and text-rendering operations' but graph.mjs is a single function projectSignGraphTopology(graph); those live in metrologic. It says cell-graph is over 'bilattice-relation' while the code imports metrologic/chu.
- Tests cover only 7 of 21 modules (carrier-refinement, cell-graph, cellular-sheaf, chu-term, graph, hierarchical-circuit, relational-value); no tests for site, valuation, fiber, cohomology, paths, mesh, pam, circuit-trace, relation-adapters, diagram*. (Per repo guidance tests are not a success measure, but it indicates unexercised code.)
- cellular-sheaf.mjs: numeric R^d stalks only; no FOUR/paraconsistent stalks, no sheaf over a bilattice, no non-linear restriction maps, no learned/parametric restrictions, no higher cells (graph only: C^0, C^1), no gluing/descent check beyond H0/H1 counts. 'Firing' (ClosureFlowDynamics) is a threshold-crossing label on a smooth linear flow, not a discontinuous dynamics. Laplacian and coboundary rebuilt from scratch every call (diffuse builds delta and L once, but applyLaplacian/hodgeCheck/others rebuild), Map-based, no CSR, findIndex vertex lookup by coincidenceKey (O(V)) in cochain/diffuse pinning; exactCoboundary is dense BigInt; none of this scales beyond toy sizes. alpha=1/Gershgorin makes convergence slow (condition-number dependent), maxSteps 1e5.
- cohomology.mjs: cohomologyOfCells ignores predicates (all collapse to 'edge'), so H1 is graph-cycle rank not logical contradiction; duplicates cellularSheaf constantSheaf(dim 1) (file says they agree). uniqueBy is O(n^2) via coincides while site.mjs uses O(n) canonical-byte keys (inconsistent). pricedNerve: causal leg (e) and mint/jump legs (c) explicitly not computed; colimit max(mass, causal) only bounded below. The long doc comments cite Obsmetrologia theorem names (CurrencyCocone, QuantumContextuality, incons_iff_one_le_topMass, mergeRecord_topfree_iff_compatible) as if the JS realizes them; the JS only counts tallies.
- valuation.mjs: 'sheafOfValuation' is just {kind:'signgraph.sheaf', section}; 'presheaf' is {site, traces[]} (a list of valuations), no restriction maps or functoriality, no gluing condition. posit checks membership in O(n*m). The sheaf/presheaf vocabulary is attached to a typed list.
- site.mjs: the 'small category' is a presentation of generators (converse, projections, specializations) with no composition, identities, or law checks; closeSpecialization is a naive fixpoint with quadratic nested loops and repeated `has` scans (O(E^3) per pass worst case). transportRules only fire for cells that exist in the site (so unobserved general cells get no rule), and only produce for-up and against-down; no composition with converse/projection, no inverse/domain-range rules.
- fiber.mjs: allPairs(entities) is N^2 and every fiber op scans `values.find` linearly; quantifier generators are O(N^3)-O(N^4). The adjoint relations (exists left adjoint, forall right adjoint to pullback) are asserted by construction; only Frobenius/fusion/residuum preservation are checkable, and sameFiber default pairs/checks are per-instance, not universal. Order bottoms and tops come from FOUR; no infinite or transfinite value set (README promises 'transfinitely-valued' but everything is exactly 4-valued).
- hierarchical-circuit: FOUR truth tables are exponential (4^k, k<=6); synthesis re-runs the whole-circuit fixpoint for every input row of every factor with no memoization; behaviorAt uses linear rows.find with canonicalEqual; monotonicity check is O(rows^2) per factor. Net modes tensor/par are checked syntactically but par's consensus semantics is only 'carries chain+contract', not simulated. Profile string drift: the CDDL (hierarchical-circuit.v3.cddl) says 'org.emsenn.rmn.hierarchical-circuit.v3' and 'org.emsenn.rmn.circuit-assembly.v1', but the code uses 'org.emsenn.sen.hierarchical-circuit.v3' / 'org.emsenn.sen.circuit-assembly.v1'. Heavy domain constants (CAIP-10 accounts, sovereign assemblies, die) outweigh the logic. Duplicated helper snippets (CAIP10 regex, exactKeys, ni, fail) copy-pasted across hierarchical-circuit, circuit-trace, carrier-refinement.
- circuit-trace: group is hardcoded (C4 semidirect Z^2, square-grid frames only); fuel capped at 64; receipts are asserted, not derived from anything (no tiling generation, no consistency solver); 'Landauer/price-erasure' and 'economicCurrentAffinity' are accounting side-channels with no physical computation behind them; the Chu seam test is just left==right.
- chu-term.mjs: re-encodes metrologic's dual/transpose as SEN terms but proves nothing (involution is evaluated per input, not proved); only dual and lookup exist (no tensor/par/implication/Chu morphism terms); the doc examples import '@red-cup-engineering/relating' which is not a declared dependency (stale from a removed package); 'short-circuit' in lookup folds the whole list anyway.
- cell-graph.relationGraphOfCells builds the weight matrix by filtering all pairs for every (row,column) entry (O(T^2 * P)) and uses O(T) coincidence indexOf; relationGraph/flowNetwork require a 'SectionCarrier' type that is not defined in this package.

- pam.mjs: every read/query rebuilds the entire valuation by scanning the full relation web (O(history) per call); polarity is only for|against so FOUR is derived from counts of witnesses; 'reindex' is function precomposition without checking it is a site morphism; no inference/propagation step connects dispatch to the site's transportRules; the only time notion is total row order (ordinal, relationIndex), no causal (partial) order.
- diagram.mjs contains type-annotation whitespace residue (e.g. 'value         )                                    {') from stripped TypeScript, and four format projectors with no relation to the inference substrate; diagram-sequence imports '@red-cup-engineering/signgraph/diagram' (a self-reference) and describes itself as 'MetroPlat' code, in a file inside signgraph: misplaced.
- Layering is violated in places: package.json depends on eavt, xml-document-rendering-service, json-schema, content-engineering (rendering and storage) so the 'pure networking' package pulls in presentation (SVG/XMI) and persistence. A vendored copy of an older signgraph exists at services/public-services-section/.../koios-news-services-section/vendor/runtime/red-cup-engineering-signgraph-cd245b62 (duplication).
- Absent entirely from SignGraph: light cones / causal partial orders (past cone = premises, future cone = consequences), tilings (Wang, substitution, sofic, aperiodic order), bead/weaving structures, FCA lattice/implication-basis computation, Curry-Howard-Lambek beyond SEN typing in relational-value and the Chu-dual term, any learning/optimization of restriction maps, any attention/softmax-like content-dependent mixing, any probabilistic or stochastic layer, GPU/batch numerics.

## Attachment points

- Foam as a cellular sheaf of FOUR-valued evidence: lift cellular-sheaf.mjs from R^d stalks to stalks that are knowledge-ordered FOUR vectors (or real vectors tagged with for/against pairs, i.e. two coupled sheaves, evidence and counter-evidence), restriction maps = predicate moves from site.mjs (converse, subject/object projection, specialization). Diffusion then becomes settlement; H1 of the pair is paraconsistent contradiction count. Join cohomology.pricedNerve (counts) with cellular-sheaf H1 (rank) as one obstruction report.
- Sheaf diffusion as the attention substitute: nodes = tokens/predications/agents, edges = candidate relations; make restriction matrices a function of the endpoint cells (content-dependent, e.g. produced by fiber/site rules or a learned small map) and run diffuse() for a fixed K steps (or to convergence) with the prompt/premises pinned as boundary conditions; output = harmonic section (consistent completion). Per-edge residuals and crossings give an interpretable attention-like map; H0/H1 give a certificate of how many consistent completions exist and where contradiction lives.
- Foam physics literally: equate diffuse() energy 1/2||delta x||^2 with a surface-tension energy, add pressure/volume constraints per cell (bodyBarSheaf handles rigid contacts; add vertex/film stalks), use rigidityReceipt/bodyBarReceipt H0/H1 as the mechanism/self-stress counts of a bubble cluster. apps/holofoam/src/structure.mjs already consumes bodyBarSheaf and solveNormal, so the foam simulator and the inference substrate can share one sheaf core.
- Plateau/Euler constraints as cohomological checks: use cohomologyReceiptOfCells for V - E + F style counts on the foam's wall graph; extend cohomology.mjs from 1-cells to 2-cells (faces) to get delta^1 and H2 (the foam's bubbles), making the Hodge Laplacian (grade 1) available for 'film' flows.
- Light cones on top of pam.mjs and paths.mjs: replace the total (ordinal, relationIndex) window with a causal partial order; define past cone of a cell as the cells reachable backward through composed paths (paths.compose iterated to closure) with the sheaf's restriction maps as transport, future cone forward; premise set = past cone, consequences = future cone, and a cell's reading settles only from its past cone (coordination-free). cohomology.pricedNerve's missing causal leg (e) is exactly the hook for this.
- Chu semantics for the model's inputs/outputs: cellGraph(cells, observations) makes a Chu space of cells x observations; use metrologic chuMap (forward map + backward demand, adjointness) as the interface contract between two model components (forward: data/messages; backward: demand/gradient-like queries). chu-term.mjs shows how to express the dual as a SEN term; extend with tensor/par/implication terms so a model's layer interfaces are typed Chu terms (CHL: composition = proof).
- FCA layer from mesh.mjs: build a differentiable-free but exact concept-formation layer: contexts from fiber readings (subject x (predicate,object) with FOUR incidence), compute the full concept lattice and stem base, and use concept intents as the discrete 'features' feeding the sheaf's stalks; use generatedConcepts' aliases/broader as automatic merging/subsumption (symmetry quotient of the foam). Extend incidence to paraconsistent (use against-evidence) to get FCA over a bilattice.
- Circuit layer as the deductive core: compile site.transportRules plus SignChain rules into hierarchical-circuit leaves (monotone FOUR gates), compose by nets into a larger monotone network, settle by the existing least-fixed-point loop (this is Kleene iteration, i.e. forward-chaining). Memoize by content-address (hierarchicalCircuitId) to share subcircuits across inputs. Alternate with sheaf diffusion: gates as discrete steps, sheaf as continuous relaxation, with 'par' nets as the only places where consensus is allowed.
- Tile coloring via assayCircuitTrace: generalize its (C4, Z^2) affine connection to a configurable edge-label alphabet (Wang colors on edges, substitution adjacency) and treat a tiling as a sheaf on the grid graph whose stalks are tile types and restrictions are edge-color projections; H0 = valid tilings (global sections), H1 = local-to-global obstructions (aperiodic order shows up as nonzero holonomy / non-extendable patches). The trace's dispositions (closed-flat, rotational-protected-border, defects) are already the vocabulary for 'consistent', 'protected', and 'defective' seams.
- Weaving/bead hook: a bead row as a loop of seams (the trace is a closed cyclic list of <=64 steps with orientation +-1, which is exactly a two-hand over/under crossing sign); use the orientation/translation fold as a finite observable of an aperiodic word, and the cohomology of the bead graph (cohomologyOfEdgeGraph) as its topological summary.
- pam.mjs as agent/node protocol: PAM messages {sender, claims, polarity} are the inter-node wire format; wire dispatch to apply site.transportRules automatically (currently absent) so each message triggers local rule firing and returns read witnesses. relational-value + ni identity make the whole exchange content-addressed, so a node's state can be replayed (replayPam) coordination-free.
- Chu/CHL training-free learning: use truthDominanceFrontier / checkPointTruthDominance (metrologic) over cellGraph spaces to compare candidate hypotheses by truth dominance, and fiber residuum/fusion to compute entailment margin between a premise cell set and a conclusion; surface these as scoring functions in place of logits.
- Performance route: port coboundary/Laplacian to a cached CSR with typed arrays and precomputed vertex index maps, memoize delta and L on the sheaf object, and add Chebyshev or conjugate-gradient diffusion (solveNormal already has CGLS) to reach 1e5-1e6-node graphs; keep the exact Q path (cellularSheafCohomology) as the audit oracle for small subproblems.
