## 1. How text enters Sign* (and how it leaves)

### 1.1 Entry (listening direction)

`COMM`/src/speaking/listening/parsing/carrier.mjs:
- `admitCommunication(tokenInput, claimInput)` builds `utterance(Mark, Mark)` from `@red-cup-engineering/signcell/cell`. Raw string text becomes `Mark {boundary:"communicating.document", text}`; claim defaults to `Mark {boundary:"communicating.claim", claim:"uttered"}`. Returns frozen `{kind:"communicating.carrier", utterance, articulation: signcell.utterance.articulate(utterance)}`.
- This is the literal `(token, claim)` utterance of the lead's spine. `communicationDocument(carrier)` reads the text back out.
- So the SignCell entry is: string -> Mark -> Utterance -> articulation. No SignCell is yet produced for words; words enter later (below).

Chain actually executed by `COMM`/src/holography/index.mjs `read(text,bundle)` (the "headline endomorphism") and `settle(text,bundle)`:
1. `articulateCommunication` (parsing/articulating.mjs, 293 lines): tiered Spans (document/block/sentence/clause/word/quote/rule). Word tokenization via `@red-cup-engineering/computer-text-content-engineering-services-section/text tokenizeWords`, or bundle.segment hook, or per-character for script-segmented langs (`grammar.segmentation.wordBoundary === "script"`).
2. `parse(sentenceSpan, base, bundle)` (parsing/parsing.mjs) = `construe` -> `descend` -> readouts:
   - `construe` (construing.mjs): per word `tag()` (tagging.mjs: closed-class lexicon lookup, then numeric regex, then bundle morphology regex suffix rules, else default `"noun"`), `features()`, then `relate()` (relating.mjs, 368 lines: rule-proposals of dependency arcs nsubj/dobj/det/amod/advmod/prep/pobj/obl/case/discourse/ccomp/mark by word-order/particle/case strategies from `bundle.grammar.roleStrategies`), then `tell()` (telling.mjs).
   - `tell` turns words+arcs into "entries" = (subject, predicate[, object], reading) with readings drawn from FOUR (`potential`=for-only, `active`=against-only, `stable`=both, `absurd`=neither). A noun+verb dual-tag word gets is-noun/is-verb entries `absurd` unless arc evidence settles it ("House thesis: morphology must not argmax"). PP high/low attachment gets an `absurd` question cell with specialization edges (pp-high/pp-low -> pp-attaches-high). Subject-verb agreement gets agree-sg/agree-pl true/false cells and a `subject-verb-agrees` question.
   - `descend` (descending.mjs): builds SignCells (`cell(subject,predicate,object, witnessedReading(reading,"construal"))` plus reflexive has-/is- projections), a `site`, and runs `settleValuation` from `@red-cup-engineering/signcraft/settle` with SignChain `rule`s generated from specialization edges (for => for, against => against). Reads back `evidenceAt`. THIS IS THE ONE PLACE text-derived claims are genuinely SignCell -> SignChain -> SignGraph (site/valuation) -> SignCraft (settle) end to end.
   - Readouts: words with connected status, arcs with value, "answers" (settled question cells), `fold` compositions/tower, conflicts (status ambiguous) and voids, attributions, modality.
3. `parseForest` (forest.mjs): one "reading" per SENTENCE. `cohomology(result)` gives glued/obstructions. Schema-asserted via `schemaFrom` carriers.
4. `lambekProofOfForest` (lambek.mjs, 232 lines), `discourseStateOfForest` (understanding/discourse-state.mjs, 285 lines), `discourseInformationOfState` (198 lines; topic/commitment/repair entropy, mean surprisal, redundancy), roles/polarity/tense/scope/presupposition/logical-form (understanding/semantics/*), `resolveReferences`, `grammaticality`.

Other entry doors:
- Newswire (`COMM`/src/messaging/newswire/{feed-arrivals,source-arrival,source-acquisition,syndicate-feeds}.mjs): RSS/Atom -> SCIS v2 CloudEvents (`messaging/cloudevents.mjs`, id = hash of normalized {source,type,time,data}); README: "Newswire does not write articles. ## 2. Grammar / lexicon formalism that exists

### 2.1 The "language bundle" (the lexicon+grammar formalism): JSON schema `languageManifestSchema` / `languageBundleSchema` in `COMM`/src/speaking/listening/algebra/manifest.mjs (317 lines) and `profile.mjs` (159)
Manifest = `{kind:"communicating.language-manifest", bundle, witnessJournal[], sen[], lambek{categories,judgments}, sofic{alphabet,graph,factor,sample,note}, chu{pts,sts,matrix}, discourseCover{entities,cells,components,note}}`.
Bundle = `{meta{name,code,script,direction}, lexicon{determiners,prepositions,pronouns,conjunctions,auxiliaries,copula[,negators]}, morphology{suffixRules[{pattern(regex),tag}], featureRules, rootPatternRules[{pattern,tag,root,template,features}] (non-concatenative), numberSuffixPattern, verbFormRules, numberWords, irregularPlurals, irregularVerbs, verbStems}, reference{pronouns,nameGender}, wordOrder(SVO|SOV|VSO|VOS|OVS|OSV|free|topic-comment), roleBy("case"), grammar(GrammarProfile), registerFiber, attachment{determiner,adjective,subject,object: left|right}, segmentation{sentenceTerminatorPattern, abbreviations}}`.

### 2.3 Lambek: `parsing/lambek.mjs`
`lexicalCategory(word,arcs)`: tag-based assignment — det -> `NP/N`, adj -> `N/N`, prep -> `(NP\NP)/NP`, adv -> `(NP\S)\(NP\S)`, aux -> `(NP\S)/(NP\S)`, verb -> `(NP\S)/NP` if dobj arc exists else `NP\S` if nsubj arc else `S`; noun/pron -> `NP`; else `N`. Categories are chosen FROM the dependency arcs that the heuristic parser already produced; "proof steps" are a relabeling of those arcs (dobj/pobj -> right-residual-application, nsubj -> left-residual-application, det/amod/advmod/prep/obl/case/ccomp/mark/discourse -> right-residual-application with hard-coded conclusion `NP` or `NP\S`). `proven = reading.glued && reading.complete && hasSentence`; no sequent is actually derived, there is no cut/associativity search, conclusion types in `arcStep` are not checked against premises. The only genuine mathematics attached is `laws(booleanCommutativeLambekAlgebra)` from metrologic (the two-element-ish boolean commutative Lambek algebra — which is a degenerate case where `\` and `/` coincide). Header comment says exactly this: "it does not search a complete grammar calculus". So: Lambek here = labelled dependency arcs + a witness that a 1-model satisfies residuation laws. Lambek is NOT sound/complete for what the parser does. (This is the opposite of the lead spine's syntactic-concept-lattice, where the residuated lattice IS the language.)

Relconlang's supplied matrix: pts = [ta, na, sha, mu], sts = [truth, falsity]: ta=(potential,absurd), na=(absurd,potential), sha=(stable,active), mu=(absurd,absurd).
