QwzSpace is the Group's 3D game engine. Leader, 2026-10-15:
"QwzSpace is our 3d game engine."

Its intended scope includes authoring and running 3D games and worlds: scenes,
rendering, simulation, assets, interaction, game logic, multiplayer and useful
development tools. Its room, transport and replay code supplies capabilities
within that engine; it does not define the ceiling of the product.

The primary meet-then-beat peers are complete 3D game engines, including Godot
and Bevy. Multiplayer frameworks remain comparisons for the networking portion.
The application belongs under the game-systems engineering parent, with its own
repository in red-cup-engineering. Placement and repository receiving are
separate operations; this definition does not assert that either has occurred.
