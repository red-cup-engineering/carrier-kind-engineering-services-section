**SignChain** is the application of **computer code** among the four Sign
libraries (SignCell : SignChain : SignGraph : SignCraft :: Data : Code :
Networking : Systems). It requires SignCell and `metrologic`.

SignChain provides the logic structures and methods that all computational code
can share. Mathematically it is the bilattice of knowledge order and truth
order that forms evidence. It is what earlier records framed as a proofing
engine or a memetic processing unit.

SignChain is meant to beat LangChain (Leader, 2026-10-09): the chain of
inference calls an agent composes runs on SignChain's evidence logic, not on a
foreign orchestration library.

  SEAVT is SignChain or a data package beneath it.
