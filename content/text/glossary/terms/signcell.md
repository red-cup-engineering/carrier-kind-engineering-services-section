**SignCell** is the application of **computer data** among the four Sign
libraries: SignCell : SignChain : SignGraph : SignCraft :: Data : Code :
Networking : Systems.

SignCell provides the data structure of the Group's **semiotic cell** and the
methods that all computational data can share, informed by the house's
mathematical research into computational logics. It requires `metrologic`, the
JSNode carrier of Obsmetrologia. The semiotic cell has also been called
Semiotic Cell and Closure Cell; those variants are condensed into SignCell.

Capabilities that are not the semiotic cell's data structure belong to other
packages and move out of SignCell. The Leader stated on 2026-09-25 that most of
what SignCell did then should be owned by other packages, while no package
provided what SignCell should: the semiotic cell itself.

Group software deployed as production code is shaped as MetroPlat enterprises,
FeltOS modules, AOE components and SignCells (Leader, 2026-10-08).

"SignStuff" is the Leader's spoken shorthand for "SignCell, SignChain,
SignGraph, SignCraft". It is not a name in the repository: not a word in a
record, a file, a directory or a package (Leader, 2026-10-04).
