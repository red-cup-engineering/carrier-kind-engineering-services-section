**SignGraph** is the application of **computer networking** among the four
Sign libraries (SignCell : SignChain : SignGraph : SignCraft :: Data : Code :
Networking : Systems). It requires SignCell, SignChain and `metrologic`.

SignGraph provides the graphing structures and methods that SignCells and
SignChains form. It is the higher-order categorical layer above SignChain; the
2026-09-04 specification has it organize SignChain's bilattice as a Chu space.
It is the Group's peer of LangGraph (Leader, 2026-10-09: "SIGNGRAPH MEANT TO BE
LANGGRAPH"): agent graphs, their state and their transport run as SignGraph
structures.
