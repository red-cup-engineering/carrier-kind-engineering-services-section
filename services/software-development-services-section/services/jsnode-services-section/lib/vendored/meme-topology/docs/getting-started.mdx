## Install workspace dependencies

```bash
pnpm install
```

## Build the package

```bash
pnpm run build
```

## Generate API docs

```bash
pnpm run docs:api
```

This writes generated reference pages into `docs/api/`.

## Run the docs site

```bash
pnpm run docs:dev
```

## Production build

```bash
pnpm run docs:build
```

The site output is written to `sites/starlight/dist/`.
