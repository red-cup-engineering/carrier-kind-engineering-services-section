# Computer Information System Engineering Services Section

**Status:** Private, source-owned parent-section foundation. The requested submodule reparenting is **proposed, not complete**.

**Parent:** Red Cup Computer Engineering Services Section (this repository).  
**Requested child chain:** Language Engineering → English Engineering → PTGAE Engineering.

This section engineers systems that process information through computing, including English-language analysis, structured text rules, validated transformations, provenance and human-readable system interaction. It is an engineering context for *software implementing natural-language standards*, **not** a claim that human-language science is a subset of computer programming.

## PlainEng / PTGAE

PlainEng is the short name for Plain Technical General American English. This private and not-yet-FOSS partnership uses [Lenticule's PTGAE science](https://github.com/lenticule-science/science-services-section/tree/main/services/information-science-services-section/services/language-science-services-section/services/english-science-services-section/services/ptgae-science-services-section) and the existing [Red Cup PTGAE engineering repository](https://github.com/red-cup-engineering/ptgae-engineering-services-section).

**Already implemented as real repository links:** `red-cup-engineering/language-engineering-services-section` has an `english-engineering-services-section` git submodule; `red-cup-engineering/english-engineering-services-section` has a `ptgae-engineering-services-section` git submodule. Preserve these repos and their history.

**Not implemented yet:** the root `red-cup-engineering/engineering-services-section` currently mounts Language Engineering alongside Computer Services. It does **not** mount Language Engineering underneath this Computer Information System Engineering parent. This README records the proposed domain and migration destination but does not assert the move is complete.
