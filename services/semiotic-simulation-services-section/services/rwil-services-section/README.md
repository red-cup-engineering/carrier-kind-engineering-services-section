# Witness Journal Services Section (retired landing zone)

This section used to group packages that operate on the witness journal (the
witnessed log->state->record->content substrate, formerly named RWIL —
Relation Witness Information Log — see
`content/glossary/terms/witness-journal.md`). It is now empty: its one
package, the category-reference index, moved to
`semiotic-software-services-section/services/witness-journal-services-section/services/category-reference-index-service/`
as part of the RWIL -> witness-journal rename. This directory is a stale
landing zone pending retirement (see the semiotic software consolidation
plan's sequencing item 7); it is kept here, empty, rather than deleted, so
that removal is a deliberate act in that later pass rather than a side
effect of this rename.
