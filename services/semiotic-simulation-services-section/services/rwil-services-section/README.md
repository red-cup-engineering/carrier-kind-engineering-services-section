# RWIL Services Section

This section groups packages that operate on the RWIL (Relation Witness
Information Log) — the witnessed log->state->record->content substrate
underlying this repo's Semiotic Exchange Chain migration (see the parent
`semiotic-services-section/README.md` and repo root `CLAUDE.md`).

## What's here

- `services/rwil-category-reference-index-service/` — indexes RWIL category
  members (immutable NI references) for bounded category-scoped lookup.
