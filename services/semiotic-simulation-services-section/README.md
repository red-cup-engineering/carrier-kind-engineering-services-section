# Semiotic Services Section

This section groups red-cup-engineering packages facing the Semiotic Exchange
Chain — the ActivityPub + EVM + A2A + x402 + UCAN + EAVT target this repo is
mid-migration onto (see repo root `CLAUDE.md`). Where other sections broker a
resource or run a persistent host, the packages here name, witness, and
exchange the settlement's own semiotic content: RMN (Relation Model Notation)
identity, WitnessJournal (Relation Witness Information Log) indexing, and the chain's
own exchange substrate.

## What's here

- `services/witness-journal-services-section/` — witness-journal-facing capability cells (witness
  log indexing and reference services).
- `services/semantic-content-identify-service/` — content-address/semantic
  identity service for the settlement's own semiotic content.
- `services/semiotic-exchange-chain-services-section/` — design and
  architecture material for the Semiotic Exchange Chain itself.
