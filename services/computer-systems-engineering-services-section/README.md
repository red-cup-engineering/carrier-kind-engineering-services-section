# Computer systems services section

Owns capabilities whose primary subject is a composed computer system,
including operating systems, agent and inference systems, interface systems,
blockchain systems, proof-assistant systems, documentation systems, and
programmable multi-user dungeons. Protocols that exist to serve a particular
system kind belong beneath that system rather than at the generic
computer-protocol level.

At the peer taxonomy level, computer code, computer data, and computer
networking provide the three coordinate concerns whose composition is owned by
computer systems. The four sections therefore form one code–data–networking–
systems quartet.

Lean and MkDocs are seated here as named system kinds; their source code still
belongs to code services, and the data they consume or produce still belongs to
data services. Likewise, a blockchain is seated here because it composes code,
data, and networking into an operational ledger system. Cryptographic
commitments used by that system remain data services rather than becoming
properties of the chain.
