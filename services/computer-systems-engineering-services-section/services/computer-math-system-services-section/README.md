# Computer math systems

Applications for computing and experimenting with mathematics live here. The shared JavaScript mathematics every layer uses is not an application: it is [Metrologic](../../../computer-data-engineering-services-section/lib/metrologic), the data layer's mathematics.

- [Laplacianizers](apps/laplacianizers) and [Laplacianizability](apps/laplacianizability) hold the Macaulay2 and Python Laplacian research tools.
- [PyMetrologic](apps/pymetrologic) is the Python and NumPy mathematical research application.
- [Enriched categories](apps/enriched-categories) contains Python experiments over enriched categories.

Proof-assistant integration is provided by the sibling [computer proofing system](../computer-proofing-system-services-section). Scientific formalizations and their project-specific change qualification live with their mathematical subject.
