# Number Theory Runtime Service

This service realizes discrete number-theoretic calculations: Collatz orbits
and their decidable-core/keratin receipts, plus sequence-recurrence readings.
It is an executable carrier; mathematical statements and proofs about those
calculations remain in Science.

## Holdings

- `src/collatz.mts` — Collatz orbit receipts (barrier decidable-core and keratin readings).
- `src/number-theory.mts` — general discrete number-theoretic semigroup laws.
- `src/sequence-recurrence.mts` — sequence-recurrence readings.

## Founding (2026-09-11)

Cannibalized from `@red-cup-engineering/feltos`'s `src/lib/math/number/{collatz,number-theory, sequence-recurrence,index}.mts` per the Founder's ruling that FeltOS carries no functionality beyond what it needs as a MUD server.
This subtree carried no MUD/game-specific behavior and no cross-references into feltos's own predication/fixpoint/topology/order modules -- it moved over unchanged.
