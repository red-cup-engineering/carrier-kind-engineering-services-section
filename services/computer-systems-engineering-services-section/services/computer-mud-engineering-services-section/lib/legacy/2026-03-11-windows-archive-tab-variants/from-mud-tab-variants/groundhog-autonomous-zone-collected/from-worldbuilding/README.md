# Groundhog Autonomous Zone

A paracosm distinct from the [emsean paracosm](../emsean-paracosm/), grown from personal logs, conversations, sessions, and lived imaginative practice.
Existing material is in [`triage/content/buckets/personal/Groundhog Autonomous Zone/`](../../../engineering/triage/content/buckets/personal/Groundhog%20Autonomous%20Zone/) and in the Fennel side as [`tab/archive/gaz-ips/`](../../../engineering/toys/tab/archive/gaz-ips/).

The content shape differs from emsean-paracosm: less structured-fiction, more session logs, conversations, ongoing lived material.
The schema may need additional `kind:` values (e.g., `event`, `session`, `conversation`) — assume `place` / `being` / `thing` / `term` / `text` for now and add as the extraction work surfaces what's actually needed.

## Layout

- `terms/` — GAZ-wide vocabulary.
- `texts/` — GAZ-wide prose, lore, longer-form material.
- (Sub-region directories may emerge if GAZ has internal regions; for now treat as a single flat paracosm.)

See [the schema](../SCHEMA.md) for entry conventions.
