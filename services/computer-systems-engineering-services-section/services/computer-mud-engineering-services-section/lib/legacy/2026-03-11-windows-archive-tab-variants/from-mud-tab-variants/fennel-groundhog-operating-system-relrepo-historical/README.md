# MarMUD *in midst of a million nightmares, a hold on one dream*

***MarMUD*** is the working name of the MUD engine being built by and for the GAZ.

## Use

### Client

	$ telnet localhost 4242

### Admin

#### Running the System

    $ make lsr

#### Building the System

    $ make gos-bin
