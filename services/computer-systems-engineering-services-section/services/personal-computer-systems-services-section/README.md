# Personal computer systems services section

Owns capabilities whose primary subject is a composed computer system scoped
to a single person's devices, accounts, and information environment, rather
than an enterprise, public, or otherwise shared computer system. It narrows
computer-systems-services-section to individual scope, the way
domestic-services-section narrows physical operations to a household.

A system seated here still composes computer code, computer data, and
computer networking; only its customer and authority boundary differ from an
enterprise or public system of the same kind. Device hardware, and account or
identity administration not specific to a composed system, remain outside
this section's ownership.

## Services

- `personal-health-computer-systems-engineering-services-section` — owns
  personal computer systems composed specifically to support one person's
  health practices and practitioner-owned health state.
- `personal-intelligence-systems-services-section` — owns personal inference
  and agent systems operated within an individual's authority boundary.
