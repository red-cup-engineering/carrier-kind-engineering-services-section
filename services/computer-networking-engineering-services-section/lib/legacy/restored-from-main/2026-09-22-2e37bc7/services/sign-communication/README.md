# Sign Communication

`@red-cup-engineering/sign-communication` owns pure language-neutral communication
carriers: messages, communicative faces, channels, translations, and speech-act
intent. It has no text parser, grammar, corpus, codec, I/O, or dependency on the
retired Lenticule implementation.

`SignCraftPort` admits FOUR-valued predications and `SignChainPort` witnesses an
already-admitted claim. They are explicit composition ports because these source
packages are not yet registry-published; a future released dependency edge must
use their exact registry pins, never a source-relative or `file:` import.

Language parsing, realization, reading, manifests, and evidentiary judgments
remain language-fiber adapters. `legacyCommunicationContractMap` states that
boundary in the public type contract so a migration cannot mistake a fiber for
generic executable semantics.
