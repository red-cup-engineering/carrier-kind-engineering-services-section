# Computer networking engineering services section

Owns reusable protocols and networking topologies that communicate computer data between systems.
Application-layer protocols remain here when their defining responsibility is interoperable exchange; Web application and server composition remain under Web Services.

MCP engineering owns its paired HTTP client and server boundary apps; the server owns incoming HTTP policy while the client owns outbound observation.

## Services

- `http-services-section` and `websocket-services-section` — HTTP/HTTPS and WebSocket coding, negotiation, authentication, and message semantics.
- `a2a-services-section` and `mcp-engineering-services-section` — agent communication and tool-interface protocol applications.
- `activitypub-services-section`, `micropub-service`, and `webmention-service` — federated publication and IndieWeb exchange.
- `oauth-services-section`, `object-capability-services-section`, and `ucan-services-section` — authorization and delegated-capability protocols.
- `web-mesh-services-section` — peer-to-peer discovery, transport, and mesh topology.
- `x402-services-section` — HTTP payment protocol services.

`google-drive-services-section` publishes content-addressed artifacts into Google Drive.
